# GPU eQTL 1.9.2.4

This release includes [PR #32](https://github.com/robbyjo/GPU_eQTL/pull/32), repairing pooled association information near cohort variance boundaries. A converged null could still throw `Invalid pooled score information`, or produce an inaccurate effect, when the inverse-information correction lost precision.

Scalar and GPU products now use the orthonormal weighted design. If subtraction would remove at least 99% of the raw predictor norm, equivalent explicit residual scoring with one reprojection stabilizes both information and numerator. The model, null optimizer, bounds, `1e-6` convergence criterion, chi-square(1) score law and existing `1e-12` relative collinearity threshold remain unchanged. Nonfinite and materially invalid information still fail explicitly. See the [method and limits](https://github.com/robbyjo/GPU_eQTL/blob/master/docs/POOLED_PEDIGREE_SCORE.md).

**Pooled upgrade requirement:** use fresh pooled association result/checkpoint paths when upgrading from v1.9.2.3 or earlier. Pooled result signature version 5 prevents reuse of old association parts. The `pooled-null-v4-weighted-qr` key and immutable format from v1.9.2.3 remain compatible under all existing exact trait/model/sample/algebra checks: the score basis is reconstructed from verified weights and geometry. Preserve earlier results and null files. Pre-v1.9.2.3 nulls retain their earlier migration requirements. Legacy/set identities and aligned raw-cache formats retain their compatibility checks; prior BCF migration requirements still apply when upgrading from an older reader.

The reviewed local suite passes 254 tests: 249 passed and five optional skips, with no failures/errors. The published v1.9.2.3 JAR reproduces both synthetic regressions: a native OpenBLAS exception and an incorrect Java effect. The repair matches independent within-cohort GLS effects, standard errors, statistics and p-values across predictor offsets, and preserves true-collinearity classification. Existing dense-R, exact-mask, response-scaling, cache, CLI and resume checks pass. Local validation uses JDK25 targeting Java17, RTX2080 CUDA/OpenCL, OpenBLAS and Java reference paths. Required hosted Linux/Java17 CI passed. Exact-JAR boundary/GPU/immutable-null-reuse checks, compatibility, public downloads and website deployment are recorded in the [release receipt](https://github.com/robbyjo/GPU_eQTL/blob/master/docs/release-1.9.2.4/verification.json).

Release verification uses synthetic fixtures and does not resume production. The PR separately records restricted-host and A100/H200 diagnostics; those controlled observations are not in this repository. Many masks and large connected pedigrees can remain expensive. No full-cohort calibration/throughput, fresh macOS, other-vendor GPU or concurrent multi-GPU validation is claimed by this release task.

Download `gpu-eqtl-1.9.2.4-universal.jar`, `SHA256SUMS` and `RELEASE-MANIFEST.txt` from this release. Java17 or newer is required.
