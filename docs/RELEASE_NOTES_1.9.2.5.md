# GPU eQTL 1.9.2.5

This release includes [PR #35](https://github.com/robbyjo/GPU_eQTL/pull/35), resolving pooled REML line searches that can reject useful downhill steps near variance bounds. Independently rounded full likelihoods could hide a tiny improvement, leaving an estimable fit above its strict convergence threshold.

The line search computes the same objective change directly from covariance ratios using `expm1`/`log1p`, the current whitened residual and a small relative fixed-effect information factor. The statistical model, absolute objective and gradient, Armijo allowance, component bounds, total iteration budget, `1e-6` projected-score criterion and association score law are preserved. No pooled dense projector or GPU kernel is introduced. See the [method and limits](https://github.com/robbyjo/GPU_eQTL/blob/master/docs/POOLED_PEDIGREE_SCORE.md).

**Pooled upgrade requirement:** use fresh pooled result/checkpoint paths and refit nulls. Result identity `pooled-pedigree-block-v6-relative-reml` and shared-null key `pooled-null-v5-relative-reml` prevent reuse of older fitted state. Preserve previous outputs, checkpoints, diagnostics and immutable null files. The null byte format, legacy/set identities and aligned raw-cache formats retain their existing compatibility checks. Earlier BCF migration requirements still apply when upgrading from an older reader.

The reviewed local suite passes 260 tests: 255 passed and five optional skips, with zero failures/errors. The new native boundary regression fails on the published v1.9.2.4 JAR. Java/OpenBLAS tests recover independent boundary-limit variances and association statistics and resolve analytic changes near `1e-15`. Review added six independent dense-R references for unequal component moves in complete/incomplete masks, checked forward and backward in both engines; the four existing R reference files regenerated exactly. Existing dense-R likelihood/gradient/association, masks, scaling, cache and resume checks pass. Required hosted Linux/Java17 CI passed. Clean universal packaging, exact-JAR boundary/search/GPU/CPU/migration checks, public assets and website verification are recorded in the [release receipt](https://github.com/robbyjo/GPU_eQTL/blob/master/docs/release-1.9.2.5/verification.json).

Release verification uses synthetic fixtures and local RTX2080 CUDA/OpenCL, OpenBLAS and Java references. Production remains held; no restricted-host or private cohort association is resumed by this task. The PR separately describes controlled diagnostics and expanded GPU work, which was reported in progress at review; no completion claim is inferred here. Full-cohort calibration/throughput, fresh macOS, other-vendor GPU and concurrent multi-GPU validation remain unclaimed.
