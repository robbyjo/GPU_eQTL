PowerShell 
java -Xmx12g --enable-native-access=ALL-UNNAMED `
  -jar target\gpu-eqtl-2.0.0-SNAPSHOT-all.jar `
  --genotype cohort.vcf.gz --genotype-format vcf `
  --expression expression.csv --covariates covariates.csv `
  --genotype-id-column participant_id `
  --expression-id-column sample_id `
  --fixed-covariates Age,Sex,PC1,PC2 `
  --analysis eqtl --precision fp64 `
  --threshold pval 1e-4 --output results.csv

Before computation: add --validate-only to check metadata, alignment, covariate rank, missingness policies, and residual degrees of freedom without initializing association work.

Precision over shortcuts

Acceleration is an implementation detail. Correctness is the product.

GPU eQTL keeps fixed-effect rank decisions, sample order, thresholds, degrees of freedom, and output identifiers explicit and testable across backends.

Read the precision contract →
FP64

Double precision by default

FP32 is always an explicit approximate mode. CPU and accelerated paths are compared against deterministic scalar references.

ID

Alignment fails loudly

Missing, duplicate, reordered, or mismatched sample IDs are audited; silent intersections are not accepted.

DF

Missingness changes the model

Exact trait masks recompute covariate rank, effective N, threshold, and residual degrees of freedom.

SHA

Reusable state is signed

Caches and checkpoints bind inputs, alignment, preprocessing, precision, and analysis settings before reuse.
