v1.9.2.8November 24, 2026Latest release

Pooled REML convergence at variance bounds

The optimizer projects outward constraint scores before BFGS steps and resets curvature when the free set changes. This resolves stalls while preserving the model, bounds, iteration budget and strict convergence criterion.

Upgrading pooled analyses Use fresh result/checkpoint paths and refit nulls from v1.9.2.7 or earlier. Keep older state and allow space for new fitter-bound rotation caches.

v1.9.2.7November 23, 2026

Optional batching for pedigree scores

Genome-wide pedigree scans can share predictor rotation and wider FP64 products across traits with the same exact sample mask. For example, choose --mixed-trait-batch-size 32 (range 2–256); the default stays 1. Complete predictors with --predictor-missing error are required.

Enabling or resizing batches Use fresh result/checkpoint paths. Compatible immutable nulls remain reusable. Budget an extra FP64 predictor cache per mask; no full-cohort speedup is promised.

v1.9.2.6November 23, 2026

CUDA bindings for Linux and Windows

Windows-built JARs now include the Linux x64 CUDA JNI libraries alongside Windows x64 bindings. Both release scripts check all twelve payloads.

Install the NVIDIA driver and compatible CUDA/cuBLAS runtime separately; exact-pattern CUDA also needs NVRTC. Numerical behavior and checkpoint identities are unchanged from v1.9.2.5.

v1.9.2.5November 23, 2026

Accurate pooled REML likelihood changes

Line search computes likelihood changes directly from relative covariance instead of subtracting rounded full likelihoods. This resolves stalled fits near variance bounds while preserving the model, bounds, iteration budget and strict convergence criterion.

Upgrading pooled analyses Use fresh pooled outputs/checkpoints and refit nulls. Result signature version 6 and the new shared-null key preserve earlier immutable files while preventing incompatible reuse. Legacy/set identities and aligned raw-cache formats retain their checks.

v1.9.2.4November 22, 2026

Stable pooled association scores at variance boundaries

Association scoring now uses an orthonormal weighted design and stable residual calculations when projection nearly removes a predictor. This fixes invalid information errors and inaccurate effects after an otherwise converged pooled null fit.

Upgrading pooled analyses Use fresh pooled result/checkpoint paths for signature version 5. Verified v4 immutable nulls from v1.9.2.3 remain reusable under the existing exact model, sample and CPU algebra checks. Earlier outputs and nulls remain retained.

v1.9.2.3November 22, 2026

Stable pooled REML at variance boundaries

Thin Householder QR stabilizes weighted residuals and information calculations when a cohort variance reaches its bound. Score-converged restarts are accepted, and identical optimizer iterates stop promptly. The model, variance bounds and strict convergence criterion are preserved.

Upgrading pooled analyses Use fresh pooled result/checkpoint paths. Version 4 and the new shared-null key preserve earlier results and prevent reuse of older fitted nulls. Legacy/set identities and aligned raw-cache formats retain their existing compatibility checks.

v1.9.2.2November 22, 2026

Correct sparse BCF header dictionaries

Reads explicit BCF header dictionary numbers for tags and contigs, including gaps and reordered entries. This fixes crashes and possible mislabeling with native bcftools files. Conflicting or undeclared dictionary entries fail explicitly.

Upgrading BCF analyses Preserve previous outputs and use fresh result/checkpoint paths. BCF QC and dosage/prepared caches use a new reader identity, preventing reuse of state decoded by the older reader. CSV and VCF identities retain their existing compatibility checks.

v1.9.2.1November 20, 2026

Shared pooled null fits across chromosomes

Compatible chromosome jobs can reuse one checksummed trait null through --mixed-null-cache-dir. Process locks serialize each shared fit, while stronger result and audit records check checkpoint integrity. Native matrix products accelerate weighted-design calculations and large-family rotations.

Upgrading Pooled signature version 3 requires fresh pooled result/checkpoint directories from v1.9.2. Keep distinct outputs and checkpoints for chromosome jobs. Existing legacy and spectral signatures and aligned raw-cache formats remain unchanged. Synthetic checks do not establish full-cohort performance.

v1.9.2November 20, 2026

Pooled pedigree-block score analysis

An opt-in single-variant model combines pedigree covariance in one cohort with fitted residual variances by cohort. It uses exact observed-sample masks, FP64 score products and optional indexed cis windows. The default mixed-model fitter remains unchanged.

Upgrading Draft pooled version-1 result checkpoints need fresh directories. Existing legacy and spectral checkpoints retain their signatures and compatibility checks. This model has synthetic validation; cross-chromosome null-fit reuse and full-cohort performance remain unvalidated.

v1.9.1.6November 20, 2026

Extreme SKAT tails with weak eigenvalues

Resolves numerical accuracy failures in highly significant SKAT tests with many weak kernel eigenvalues. A tighter integration remainder bound avoids unnecessary rounding-error accumulation while retaining every positive eigenvalue, the same distribution and SKAT-O inversion, and the 2e-11 relative accuracy target.

Upgrading Accepted version-6 set checkpoints from v1.9.1.5 remain compatible when all input, model and backend checks match. Aligned raw dosage-cache formats are unchanged. Retain failed-run diagnostics and earlier outputs; older-version migration requirements below still apply.

v1.9.1.5November 19, 2026

More stable spectral REML fits

Fixes rounding that could reject an accurately stationary spectral profile candidate. The covariance model and strict 1e-6 projected-score convergence threshold are unchanged. Select the fitter with --set-null-fitter spectral; the default remains legacy.

Upgrading Use a fresh spectral result/checkpoint directory when upgrading from v1.9.1.4. Legacy fitter identities and aligned raw dosage-cache formats are unchanged.

v1.9.1.4November 19, 2026

An opt-in spectral set-null fitter

Adds --set-null-fitter spectral for continuous pedigree-adjusted burden, SKAT, and SKAT-O tests. It reuses an error-contrast decomposition for traits with the same ordered sample mask while fitting each response’s two-component REML model. The legacy fitter remains the default.

Upgrading Keep spectral result checkpoints separate from legacy checkpoints. For spectral analyses, use v1.9.1.5 or later to include the profile-rounding fix.

Relatedness-aware rare-variant tests

Adds pedigree- and relationship-adjusted burden, SKAT, and SKAT-O, with FP64 CUDA/OpenCL operations and scalar CPU references. Exact observed-sample deletion refits each trait’s null model; SKAT-O uses joint rho-grid integration by default.
