# GPU eQTL 1.9.2.1

This release includes [PR #23](https://github.com/robbyjo/GPU_eQTL/pull/23), adding reusable per-trait null fits to pooled pedigree-block single-variant score analysis. Point compatible chromosome jobs at the same `--mixed-null-cache-dir`, while keeping their output and checkpoint paths distinct. Each immutable null has a SHA-256 payload checksum and an exact trait/model/algebra key; per-key process locks prevent duplicate fitting. See the [configuration and limits](https://github.com/robbyjo/GPU_eQTL/blob/master/docs/POOLED_PEDIGREE_SCORE.md).

Weighted fixed-design calculations and large-family rotations now use native FP64 matrix products, checked against scalar and independent dense-R references. Proportional inbred pedigree identity reductions retain the summed component bounds, and deterministic optimizer starts share the requested iteration budget. The response-normalized safeguards, exact observed masks and full score information remain in place.

Pooled result and audit parts now have model-bound SHA-256 records and exclusive checkpoint ownership. Review added regressions and fixes for two interruption cases: a lost digest index is rejected, and interrupted audit parts are retained outside directories removed during successful cleanup. Committed parts are never silently overwritten or accepted after mutation.

**Upgrade requirement:** pooled signature version 3 requires fresh pooled result/checkpoint directories when upgrading from v1.9.2 (version 2) or earlier drafts. Preserve prior outputs and diagnostics. Legacy/spectral checkpoint signatures and aligned raw-cache formats are unchanged, subject to existing exact compatibility checks. Shared nulls are independent of predictor/chromosome data but still require matching response bits, sample order, observed mask, fixed design, pedigree/group geometry, bounds, iteration budget and resolved CPU algebra.

The reviewed local suite passes 239 tests: 234 passed and five optional skips, with no failures/errors. Validation includes real RTX 2080 CUDA/OpenCL, native OpenBLAS and portable Java paths, independent base-R likelihood/gradient fixtures, finite differences, two concurrent JVMs sharing one null, corrupted-cache/checkpoint checks, and retained interruption evidence. The clean universal package, exact-JAR CLI/resume and prior-release compatibility checks, required hosted Linux/Java 17 CI, public asset downloads and website verification are recorded in the [release receipt](https://github.com/robbyjo/GPU_eQTL/blob/master/docs/release-1.9.2.1/verification.json).

Validation uses synthetic fixtures. Shared-null admission still constructs geometry; many distinct masks and a large connected pedigree can remain expensive. A synthetic engineering benchmark is included for repeatable timing and scalar/CUDA comparison, but it does not establish full-cohort throughput, scientific calibration or production-server performance. No private cohort analysis or production deployment was run for this release. Fresh macOS, other-vendor GPU and concurrent multi-GPU validation are not claimed.

Download `gpu-eqtl-1.9.2.1-universal.jar`, `SHA256SUMS` and `RELEASE-MANIFEST.txt` from this release. Java 17 or newer is required.
