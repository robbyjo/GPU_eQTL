# GPU eQTL 1.9.2.3

This release includes [PR #29](https://github.com/robbyjo/GPU_eQTL/pull/29), fixing pooled pedigree REML convergence at cohort variance boundaries and across optimizer restarts. Weighted normal equations could lose accuracy near a variance bound, and a converged second start could be discarded when an earlier nonstationary objective was slightly smaller through rounding.

The fitter now uses thin Householder QR for weighted residuals, leverage, the information inverse and determinant, through native LAPACK or portable Java. Score-converged restarts take precedence over nonstationary objective differences, and zero-length line-search steps stop the start. The Gaussian model, variance bounds, total iteration budget and maximum projected log-variance score criterion of `1e-6` remain unchanged. See the [pooled method and limits](https://github.com/robbyjo/GPU_eQTL/blob/master/docs/POOLED_PEDIGREE_SCORE.md).

**Pooled upgrade requirement:** use fresh pooled association result/checkpoint paths when upgrading from v1.9.2.2 or earlier. Pooled result signature version 4 and `pooled-null-v4-weighted-qr` prevent reuse of older nulls. Earlier outputs, null files and diagnostics remain retained. Legacy/set signatures and aligned raw-cache formats retain their existing compatibility checks. Earlier BCF migration requirements from v1.9.2.2 still apply when upgrading from an older BCF reader; see the [updates page](https://robbyjo.github.io/GPU_eQTL/updates.html).

The reviewed full local suite passes 252 tests: 247 passed and five optional skips, with zero failures/errors. The published v1.9.2.2 JAR fails the new deterministic boundary regression in Java and OpenBLAS; the corrected fitter recovers analytic cohort REML variances. New QR regressions check an analytic residual under extreme weights, orthogonality, reconstruction and input immutability. Existing independent dense-R likelihood/gradient/association, exact-mask, response-scaling, cache and resume tests pass. Local validation uses JDK 25 targeting Java 17, RTX 2080 CUDA/OpenCL, native OpenBLAS and portable Java. Required hosted Linux/Java 17 CI passed. Exact-JAR boundary/CLI checks, checkpoint migration, synthetic engineering validation, public downloads and website deployment are recorded in the [release receipt](https://github.com/robbyjo/GPU_eQTL/blob/master/docs/release-1.9.2.3/verification.json).

Release verification uses synthetic data and does not resume a production analysis. The PR separately records its restricted-host diagnostics and A100/H200 synthetic checks. Many observed masks and large connected pedigrees can remain expensive; no full-cohort calibration or throughput claim is made. Fresh macOS, other-vendor GPU and concurrent multi-GPU validation are not claimed.

Download `gpu-eqtl-1.9.2.3-universal.jar`, `SHA256SUMS` and `RELEASE-MANIFEST.txt` from this release. Java 17 or newer is required.
