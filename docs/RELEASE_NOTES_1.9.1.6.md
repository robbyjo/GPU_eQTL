# GPU eQTL 1.9.1.6

This patch resolves extreme SKAT tail calculations that could abort with `Quadratic-form inversion failed its relative error check` when the kernel has many weak eigenvalues. It includes [PR #17](https://github.com/robbyjo/GPU_eQTL/pull/17).

The tilted characteristic-function evaluator now takes the smaller of its existing rank-only integration-by-parts remainder bound and a spectrum-aware logarithmic-derivative bound. This avoids unnecessarily distant integration endpoints and accumulated FP64 rounding estimates. Every positive eigenvalue remains in the same weighted chi-square distribution. The `2e-11` relative target, 262,144 integrand-evaluation limit, quadrature limits and explicit unresolved-case failures are unchanged. SKAT-O continues to invert the same distribution. See the [bound derivation and numerical contract](https://github.com/robbyjo/GPU_eQTL/blob/master/docs/SET_TEST_FOUNDATION.md).

**Accepted version-6 set checkpoints from v1.9.1.5 remain compatible**, subject to all existing input, sample/model, preprocessing and backend/runtime checks. Spectral and legacy model identities, mixed-result signatures and aligned raw dosage-cache formats are unchanged. Retain failed-run diagnostics and prior outputs. If upgrading from v1.9.1.4 or earlier, the intervening [upgrade instructions](https://robbyjo.github.io/GPU_eQTL/updates.html) still apply, including fresh spectral checkpoints after v1.9.1.4.

The reviewed source passed the full local suite: 215 tests, 210 passed, five optional skips, zero failures/errors. Local validation used JDK 25 targeting Java 17 on Windows with an NVIDIA GeForce RTX 2080, driver 621.14; CUDA, OpenCL, native OpenBLAS and portable Java references ran. Required hosted Linux/Java 17 CI passed. The new synthetic regression reproduces the reported failure against the published v1.9.1.5 JAR. Independent positive-convolution fixtures regenerated at 70 and 110 decimal digits agree through more than 50 significant digits, including a tail near `2.12e-306`; closed-form, scale-invariance and extreme-tail quantile checks also passed. Exact-artifact, resume and publication evidence is recorded in [the verification receipt](https://github.com/robbyjo/GPU_eQTL/blob/master/docs/release-1.9.1.6/verification.json) after publication.

The release review used synthetic validation and did not run private cohort analyses or production jobs. The PR separately records aggregate Linux continuation checks. Numerical error estimates are not interval-arithmetic guarantees; FP64 subnormal/underflow and explicit work/convergence limits remain. Fresh macOS, other-vendor and concurrent multi-GPU validation is not claimed.

Download `gpu-eqtl-1.9.1.6-universal.jar`, `SHA256SUMS` and `RELEASE-MANIFEST.txt` from this release and verify the checksum before use. Java 17 or newer is required. OpenBLAS natives are bundled for Windows x64, Linux x64/ARM64 and macOS x64/ARM64; CUDA/OpenCL require compatible installed runtimes.
